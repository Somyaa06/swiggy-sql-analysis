# swiggy-sql-analysis

This project analyzes a Swiggy restaurant dataset using SQL and SQLite to discover useful insights about restaurants, cuisines, ratings, restaurant chains, and food costs across different cities/localities in India.

The project demonstrates practical SQL skills such as:

Data exploration and cleaning;
Aggregation using COUNT(), AVG(), and GROUP BY ;
Filtering with WHERE and HAVING;
Sorting with ORDER BY;
String splitting for multi-value cuisine data;
Subqueries and analytical queries;
Identifying top-performing cities and restaurant chains;

Key Insights:-

 City/locality with most restaurants	Bikaner — 1,666 restaurants;
 Most popular cuisine nationally	Chinese — 36,464 restaurant listings;
 Restaurant chain with maximum branches	Domino's Pizza — 442 branches;
 Best-rated city/locality with 50+ restaurants	Mylapore, Chennai — average rating 4.23/5;
 Most expensive city/locality	Khan Market, Delhi — avg. cost ₹446;
 Cheapest city/locality	Bathinda — avg. cost ₹167;
